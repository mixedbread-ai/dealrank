# Fonts

Linux Biolinum O, regular (version 1.1.8), bold (1.3.2) and italic (1.1.3),
the sans-serif companion of Linux Libertine, which the ACM article class uses.
The files are unmodified copies of those in the TeX `libertine` package.

Copyright (c) 2003-2012 Philipp H. Poll, the Linux Libertine project.

The fonts are dual-licensed under the SIL Open Font License 1.1 (`OFL.txt`)
and the GPL with font exception. They are redistributed here under the OFL.
Each font file carries its copyright notice and licence in its `name` table.

If this directory is removed, the figures fall back to DejaVu Sans, which
ships with matplotlib, and the layout checks warn instead of failing (see
`repro/figures/style.py`).
